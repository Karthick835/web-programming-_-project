# Rule: Always Push Changes to GitHub

Whenever code or project changes are made to this repository:
1. Always stage and commit the changes with a concise, descriptive commit message.
2. Always push the commit directly to the GitHub remote repository (`origin/main` at `https://github.com/Karthick835/web-programming-_-project.git`).
3. Never wait for the user to ask to push to GitHub; automatically push upon completing each set of changes.
